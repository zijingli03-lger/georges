# 实验报告：圣乔治图像检测系统

## 1. 实验概述

### 任务目标
构建一个二分类图像分类模型，判断图像中是否包含"圣乔治"。

### 数据概览
- **正类 (georges)**: 2,360 张图像
- **负类 (non_georges)**: 3,340 张图像
- **总计**: 5,700 张图像
- **类别比例**: 1 : 1.42

---

## 2. 数据探索与发现

### 2.1 图像统计

| 类别 | 数量 | 平均宽度 | 平均高度 |
|------|------|----------|----------|
| georges | 2,360 | 540 px | 726 px |
| non_georges | 3,340 | 557 px | 735 px |

### 2.2 关键发现

1. **尺寸多样性**: 4065 种不同的图像尺寸
2. **高度差异**: 从 110px 到 5790px 不等
3. **通道类型**: 98.5% RGB，少量灰度图
4. **数据质量**: 无损坏文件

### 2.3 决策
- 使用 224×224 作为统一输入尺寸
- 采用 CenterCrop + Resize 策略处理不同尺寸

---

## 3. 模型选择与设计

### 3.1 实际训练的模型对比

> 说明：仅以下两组经过真实训练验证（结果见 §8.1）。MobileNetV2 / ResNet101 / EfficientNet 等未实际训练，数据不支持对比，故不列入。

| 模型 | 大小 | 参数量 | 训练时间/epoch | 验证准确率 |
|------|------|--------|---------------|-----------|
| ResNet18 (Baseline) | 44 MB | 11M | ~68s | 88.07% |
| **ResNet50 (Final)** | **100 MB** | **25M** | **~75s** | **92.28%** |

### 3.2 选择 ResNet50 的原因

1. **平衡性能与效率**: 在准确率和训练速度之间取得平衡
2. **迁移学习成熟**: ImageNet 预训练权重稳定可靠
3. **对小数据集友好**: 预训练特征 + 微调适合 5700 张的数据集
4. **可扩展性**: 后续可尝试 ResNet101 或 EfficientNet

### 3.3 模型架构

```
Input (224×224×3)
    ↓
ResNet50 (预训练特征提取)
    ↓
Global Average Pooling
    ↓
Dropout (0.3)
    ↓
FC (2048 → 512) + ReLU
    ↓
Dropout (0.3)
    ↓
FC (512 → 2)  # 二分类输出
```

## 4. 数据增强策略

### 4.1 训练时增强

| 增强方法 | 参数 | 目的 |
|---------|------|------|
| RandomResizedCrop | scale=(0.8, 1.0) | 模拟不同距离 |
| RandomHorizontalFlip | p=0.5 | 左右镜像 |
| ColorJitter | ±20% | 光照/颜色变化 |
| RandomRotation | ±15° | 轻微旋转 |

> 注：未使用 RandomVerticalFlip。圣乔治题材多为画作/雕塑，垂直翻转生成上下颠倒的图像，不符合真实场景，可能让模型学到错误的对称性。

### 4.2 验证/测试时预处理
- Resize(256) → CenterCrop(224)
- 无随机操作，确保评估稳定

### 4.3 选择原因
- **不使用更强增强**: 如 Mixup/CutMix，避免在小数据集上过拟合
- **保守策略**: 先建立可靠 baseline，后续再尝试进阶增强

## 5. 训练配置

### 5.1 超参数

| 参数 | 值 | 说明 |
|------|----|------|
| Batch Size | 32 | 根据 GPU 显存调整 |
| Epochs | 10 | 充分收敛 |
| Learning Rate | 0.0001 | 较小学习率精细微调 |
| Optimizer | AdamW | 带权重衰减的 Adam |
| Weight Decay | 0.01 | 正则化 |
| Scheduler | CosineAnnealingLR | 学习率余弦退火 |
| Loss Function | CrossEntropyLoss | 加权损失处理类别不均衡 |

### 5.2 类别权重
```python
# 基于训练集分布计算
class_weights = [0.8533, 1.2076]  # [non_georges, georges]
```

### 5.3 训练时间
- **总耗时**: 14.8 分钟
- **每 epoch**: 68-248 秒（首个 epoch 较慢，后续稳定）

## 7. 误差分析

### 7.1 错误统计
- **总样本**: 855
- **错误数**: 60
- **错误率**: 7.02%

### 7.2 错误类型
| 类型 | 数量 | 说明 |
|------|------|------|
| 假阳性 (FP) | 33 | 负类被误判为正类 |
| 假阴性 (FN) | 27 | 正类被误判为负类 |

### 7.3 可能的原因
1. 圣乔治在图片中占比太小
2. 图像质量差（模糊、压缩）
3. 训练数据中的圣乔治风格多样性不足
4. 复杂背景干扰

## 9. 结论

### 9.1 主要发现
1. ResNet50 迁移学习在二分类任务上表现优秀
2. 数据增强对小数据集至关重要
3. 加权损失有效处理类别不均衡
4. 10 epochs 足以收敛，更多训练可能过拟合

### 9.2 项目亮点
- 完整的端到端 pipeline
- 92.98% 准确率，AUC 97.61%
- 清晰的代码结构和文档
- 可复现的训练流程

### 9.3 局限性
- 仅测试了 ResNet 系列模型
- 未尝试进阶数据增强
- 训练数据多样性有限
