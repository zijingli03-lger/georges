## 0. 一句话总结这个项目

> 用"别人训练好的 ResNet50 模型"当底子，用 5700 张圣乔治图片"接着教它"认识圣乔治，最后得到一个能判断"图里有没有圣乔治"的程序，准确率 92.98%。

## 1. 先分清两个概念：分类 vs 检测

这是**图像检测公司**最可能考你的点，必须分清：

| | 图像分类（本项目） | 目标检测（你毕设的 YOLO） |
|---|---|---|
| 回答的问题 | 这张图里**有没有**圣乔治？ | 圣乔治**在哪**（画个框圈出来）？ |
| 输出 | 一个标签 + 概率 | 多个框 + 类别 + 位置 |
| 要不要标注框 | 不要，只要文件夹分类 | 要，要画标注框 |

- 你毕设做的 YOLO = 检测。这次 = 分类。**"不用标注"是指不用画框，不是不做数据准备。**
- 如果对方问"为什么不用检测模型"，可以答：需求只要求判断有没有，分类够用且更简单；检测可以作为后续改进方向（需求里也允许写改进方向）。

**面试话术**："这个任务是二分类。我用的是分类模型而不是检测，因为需求只要求判断图像中是否包含圣乔治，不需要定位。如果想要更高精度，后续可以先用检测模型定位区域再做分类。"

## 2. 数据准备：两个文件夹 → 三份名单

### 2.1 原始数据
- `georges/`：2360 张，正类（有圣乔治）
- `non_georges/`：3340 张，负类（没有）
- 合计 5700 张。负类比正类多 42%（比例 1 : 1.42），这叫**类别不均衡**。

### 2.2 为什么要划分成三份（train / val / test）
类比考试：
- **训练集 train（3990 张）**：教材，模型用它学习。
- **验证集 val（855 张）**：模拟考，训练过程中随时考一下，用来选"表现最好的一次"（best_model 就是按验证准确率选的）。
- **测试集 test（855 张）**：最终考试，**模型从没见过的题**，最后用这套算真实成绩（92.98% 就是这么来的）。

> 关键点：**val 和 test 不能混**。val 选模型，test 出成绩。如果把 test 拿来选模型，成绩就虚高了（等于考前看过答案）。

对应文件：`project/data/splits/{train,val,test}.csv`，每行是一个图片路径 + 标签。划分脚本：`project/src/data/split_data.py`，按 7:1.5:1.5、每类独立划分、随机种子 42（保证每次划分结果一样）。

**面试追问准备**：
- Q：为什么 test 准确率（92.98%）比 val 准确率（92.28%）高？
- A：验证集是训练过程中"边学边考"，那时模型还没学完；测试集是学完之后考的，而且两组数据不一样，小幅差异正常。

### 2.3 类别不均衡怎么办：加权损失
- 问题：负类多，模型可能偷懒"全猜负类"也能有 58% 正确率。
- 解法：**给少数类（正类）更高的惩罚权重**。代码里 `class_weights = [0.8533, 1.2076]`，计算方法是 `总数 ÷ (2 × 该类数量)`：
  - 负类：3990 ÷ (2×2338) = 0.8533（权重 <1，少罚）
  - 正类：3990 ÷ (2×1652) = 1.2076（权重 >1，多罚）
- 效果：模型不敢忽略正类，把两类都学好。

## 3. 数据增强：免费的"造图机"

### 3.1 为什么需要
只有 5700 张图，对深度学习来说**很少**。模型容易"背答案"（过拟合）：训练图见过 100 遍，换张新图就懵。增强 = 在训练时**随机改动每张图**，让模型每次看到的都不太一样，等于免费变出更多训练样本。

### 3.2 项目里用了哪几种（`dataset.py`）
| 增强 | 干什么 | 模拟的真实情况 |
|---|---|---|
| RandomResizedCrop | 随机裁剪一块再缩放 | 圣乔治在图里占的比例、位置不同 |
| RandomHorizontalFlip | 随机左右翻转 | 画作镜像/视角不同 |
| ColorJitter | 随机调亮度/对比度/饱和度/色相 | 不同光线、不同画的色调 |
| RandomRotation | 随机旋转 ±15° | 拍摄角度略歪 |

> 注意：验证集和测试集**不做随机增强**，只做 Resize(256) + CenterCrop(224) + Normalize——考试要标准，不能随机。

### 3.3 为什么没用更强的增强（如 Mixup）
Mixup 是把两张图"叠一起"训练，效果往往更好，但更复杂、调参难。项目里选了保守策略：先保证结果稳定可解释。这是一个"说明理由"的好例子——面试官喜欢听到"我没用 X，因为 Y"这种有思考的回答。

### 3.4 Normalize 是什么
把像素值从 0-255 缩放到接近 0 的范围（按 ImageNet 的均值和标准差），因为预训练模型当初就是用这种格式训练，输入格式保持一致效果才好。这是固定做法，不用深究。

## 4. 迁移学习（本项目最核心的概念，必须会讲）

### 4.1 是什么
- **预训练模型**：有人用 ImageNet 数据集（**100 万张图、1000 类**）把 ResNet50 训练好了。这个模型已经学会"看"——能识别边缘、纹理、形状、物体局部特征。
- **迁移学习**：把别人学好的"看的能力"拿过来用，不从头学。
- **微调（fine-tuning）**：迁移学习的具体做法——保留预训练模型的大部分，**砍掉它最后一层分类头（1000 类输出）**，换成我们自己的分类头（2 类输出），然后在我们的 5700 张图上继续训练。注意我们**没有冻结骨干**，是全部参数一起接着训（`train.py` 里有 `--freeze_backbone` 选项可以做另一种方案，但最终没用它）。

### 4.2 为什么必须迁移学习
5700 张图**从零训练**一个 50 层网络根本不够，会严重过拟合。但预训练模型已经会"看"，我们只需教会它"圣乔治长什么样"——几千张图就够了。这就是本项目能短时间（15 分钟训练）达到 93% 的原因。

### 4.3 你毕设的 YOLO 其实也是迁移学习
YOLO 预训练权重 + 你的标注数据继续训练 = 同样的套路。所以**你早就会迁移学习，只是以前不知道它叫这个名字**。

### 4.4 ResNet50 是什么
- ResNet = 残差网络，50 = 50 层深。它的创新是**残差连接**（跳跃连接）：让信息能绕过某些层直接传到后面，解决"网络太深反而学不好"的问题。
- 为什么选它：效果和速度平衡（对比过 ResNet18 效果差一截，ResNet101 更慢），预训练权重成熟可靠。

### 4.5 分类头结构（`model.py`）
```
2048 个特征 → 512 → 2
```
- 2048：ResNet50 把一张图压缩成 2048 个数值（特征向量），代表"这张图长什么样"
- 512：中间层，把特征重新组合（学过的东西再加工）
- 2：输出两个分数，对应"非圣乔治 / 圣乔治"，谁分高就预测谁
- 中间有 ReLU（激活函数，让网络能学非线性）和 Dropout（随机丢弃一部分神经元，防过拟合）

**面试话术**："我用 ResNet50 预训练权重做迁移学习，替换了最后的全连接层为两层结构（2048→512→2），在任务数据上做了全模型微调。"

## 5. 训练过程：每个词都对应一个真实文件

### 5.1 基本流程（`train.py`）
1. 把训练数据按 32 张一组（batch）喂给模型
2. 模型给出预测 → 和真实答案对比算出**损失 loss**（差多少）
3. 根据损失**更新权重**（优化器干活）
4. 一组一组喂完 124 批 = 一个 epoch（完整过一遍 3990 张）
5. 每轮后拿验证集考一下，记录成绩
6. 重复 10 轮（10 epochs），保存验证成绩最好的一次为 `best_model.pth`

### 5.2 术语逐个解释
| 术语 | 大白话 | 项目里的值 |
|---|---|---|
| Batch size | 一次看几张再算账 | 32 |
| Epoch | 全部图过一遍算一轮 | 10 |
| Loss | 模型错得多离谱 | 从 0.42 降到 0.044（越来越小） |
| 优化器 AdamW | 决定"往哪个方向改权重、改多大" | lr=0.0001，weight_decay=0.01 |
| 学习率 lr | 每次改权重的步子大小 | 0.0001，太小太慢太大不稳 |
| 学习率调度 CosineAnnealingLR | 训练后期自动把步子调小，帮助收敛 | 从 1e-4 降到 ~3e-6 |
| 加权损失 | 少数类犯错罚更重 | 权重 [0.8533, 1.2076] |

### 5.3 怎么看训练曲线（`training_curves.png`）
- **train loss 一直降、train acc 接近 100%**：正常，它背住了教材。
- **val acc 上不去甚至下降、val loss 回升**：过拟合信号（背教材但不会做新题）。
- 本项目：train acc 98.66% vs val acc 92.28%，差约 6 个点，**轻微过拟合但可接受**——这是正常的（模型永远比考试表现好一点）。
- 如果面试官问"为什么不再训 20 轮"，答：10 轮时验证分数已经不再提升，继续训只会加深过拟合，收益递减。

### 5.4 随机种子（`--seed 42`）
训练前把随机数固定，保证每次跑结果接近一致，别人能复现你的实验。这是"可复现 pipeline"的要求。

## 6. 评估：你报告里的每个数字是什么意思（`eval.py`）

测试集 855 张的结果：

```
混淆矩阵：
               预测负类   预测正类
真实负类(501)     468        33   ← 33 张误报（FP）
真实正类(354)      27       327   ← 27 张漏报（FN）
```

### 6.1 四个核心指标
| 指标 | 含义 | 本项目 |
|---|---|---|
| Accuracy 准确率 | 全部预测对的比例 | 795/855 = 92.98% |
| Precision 精确率 | 模型说"有圣乔治"时，有多准 | 327/(327+33) = 90.8% |
| Recall 召回率 | 真有圣乔治的图里，找回来多少 | 327/(327+27) = 92.4% |
| F1 | 精确率和召回率的综合分（两者都高才高） | 0.9279 |
| ROC AUC | 模型"排序能力"：随机抽一张正类和一张负类，模型把正类排前面的概率。0.5=瞎猜，1=完美 | 0.9761 |

> 为什么 AUC 有 0.976 但准确率只有 93%？因为准确率是"0.5 阈值切一刀"的结果，AUC 是看整体排序质量。AUC 高说明模型大部分时候很有把握，只有边界上的样本会错。**能把这两者的关系说清楚，面试官会对你刮目相看。**

### 6.2 加权平均 vs 宏平均
项目里 F1 用的是 macro（宏平均）= 两个类各自的 F1 取平均，不偏向多数类。用 macro 更能反映少数类（圣乔治）学得好不好。

## 7. 错误分析：60 张错在哪

- 误报 FP 33 张：负类被判成正类。可能原因：图里有龙、马、骑士等元素，和圣乔治画作很像；或圣乔治特征被模型学偏了。
- 漏报 FN 27 张：真圣乔治没认出来。可能原因：圣乔治在画里占很小、模糊、风格太特殊（比如现代卡通 vs 古典油画）。
- 项目已生成 `misclassified_samples.csv`（60 条，含路径和置信度）和网格图，面试前**强烈建议自己打开看几张**——能说出"这张是因为什么错的"是巨大的加分项。
- 置信度 99.9% 还判错的（CSV 前几行就是）——说明模型"自信地错"，这类最值得分析。

**改进方向（报告里已有的）**：更多数据、更强模型（ResNet101/EfficientNet/ViT）、进阶增强（Mixup/CutMix）、检测+分类两阶段。这些写在报告里作为"未来工作"，面试时被问"还能怎么提升"直接照答。

## 8. 面试高频追问清单（带参考答案要点）

1. **Q：什么是迁移学习？为什么用？** → 见 §4。重点：预训练权重 + 替换分类头 + 微调；图少所以不能从零训练。
2. **Q：分类和检测的区别？** → 见 §1。
3. **Q：train/val/test 为什么分三份？** → 见 §2.2，用"教材/模拟考/期末考"比喻。
4. **Q：数据不平衡怎么处理？** → 加权损失，权重怎么算（见 §2.3）。
5. **Q：为什么用 ResNet50 不用更大的？** → 速度和效果平衡，数据量不大时大模型易过拟合。
6. **Q：怎么看有没有过拟合？** → 训练/验证差距，见 §5.3。
7. **Q：准确率 93% 但 AUC 97%，正常吗？** → 正常，见 §6.1。
8. **Q：错误样本主要错在哪？** → FP 33/FN 27，原因见 §7（面试前去看几张实际图片）。
9. **Q：如果给你更多时间，怎么提升？** → 报告里的改进方向（§7 末尾）。
10. **Q：训练花了多久？** → 正式训练 14.8 分钟（10 epochs，RTX 3060），全流程约 2 小时纯执行。
11. **Q：为什么不用 YOLO/检测？** → 需求只要判断有没有，分类足够；检测留作改进。
12. **Q：这个项目哪些是你自己写的？** → 诚实回答：核心思路、数据准备、训练评估流程由我设计，用 AI 辅助写代码和排错。**重点是你能完整解释每一行代码的作用——只要做到了，这个答案就站得住。**
